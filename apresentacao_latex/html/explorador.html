Como um modelo de música organiza 52 compositores

Cada ponto é a média das "impressões digitais" que um modelo de música (o Anticipatory Music Transformer, treinado em música popular, sem nenhum nome de compositor) produz para as peças de piano de um compositor do acervo GiantMIDI. Pontos próximos soam parecidos para o modelo. Passe o mouse para ver os detalhes; clique para ver as peças e os vizinhos.
